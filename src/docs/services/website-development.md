# Launch Checklist

Before launch:

- All links tested
- Mobile tested
- Tablet tested
- Desktop tested
- Forms tested
- Analytics verified
- Search Console verified
- Sitemap submitted
- Robots.txt verified
- Metadata verified
- Performance tested
- SSL verified

Launch only when every item passes.

---

# Post-Launch

After launch:

- Monitor analytics
- Monitor Search Console
- Fix reported issues
- Publish content
- Improve SEO
- Review performance

A website is never "finished."

It should continually improve.
