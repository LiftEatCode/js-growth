## Honesty constraints

Do **not** claim in proposals:

- Fully automated outbound email or contact-form bots
- CAPTCHA bypass
- Rank/traffic/backlink APIs the app does not call
- Public shareable competitive reports until that product exists

When in doubt, check implementation docs under [`../development/`](../development/).
