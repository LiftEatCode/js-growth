# Local SEO Launch Checklist

> This checklist ensures every Local SEO engagement begins with the necessary information, access, planning, and preparation. Completing each item before implementation reduces delays, prevents missed tasks, and creates a consistent onboarding experience.

---

# Purpose

The purpose of this checklist is to verify that all required information, accounts, access, and project planning have been completed before active Local SEO work begins.

No campaign should move into implementation until every required item has been reviewed.

# Definition of Done

A Local SEO project is ready to begin when:

- All required access has been obtained.
- Discovery and qualification are complete.
- Research and audits have been completed.
- Initial strategy has been approved.
- Baseline metrics have been recorded.
- Client expectations have been documented.
- Internal planning is complete.
