# Website Development Checklists

> **Part of the JS Solutions Website Development Playbook**

---

# Purpose

This directory contains operational checklists used throughout the Website Development lifecycle.

Unlike the phase documents, which explain the process and philosophy, these checklists are designed for day-to-day execution.

They provide a consistent way to verify that every project meets the JS Solutions standard before moving to the next phase.

---

# Philosophy

Checklists improve consistency.

They reduce mistakes, simplify onboarding, and ensure that no critical steps are overlooked.

Every website should follow the same quality standards regardless of project size or complexity.

When in doubt, use the checklist.

---

---

# How to Use These Checklists

Checklists should be completed:

- During development
- Before client review
- Before launch
- During maintenance audits

Whenever possible, document the completion date and the person who completed the review.

---

# Continuous Improvement

These checklists are living documents.

Whenever an issue reaches production that could have been prevented, update the appropriate checklist so the mistake is not repeated.

The goal is continual improvement through documented processes.
