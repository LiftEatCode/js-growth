# Website Development Quality Assurance Checklist

> **Part of the JS Solutions Website Development Playbook**

---

# Purpose

This checklist is used before every website launch to verify that the project meets JS Solutions quality standards.

Every item should be reviewed before deployment.

Do not assume something works because it worked previously.

Verify everything.
