# GROWTH-EXP-2026-011 — Native-value post vs outbound-link post

**Status:** READY  
**Primary jobs:** AUTHORITY (native) vs TRAFFIC (link)

## Hypothesis

Native educational posts (no outbound link, or delayed link) earn more distribution than immediate link posts; link posts earn more website sessions when the job is TRAFFIC.

## Primary metric

For native arm: reach/views. For link arm: Facebook-attributed website sessions / audit landing views.

## Secondary

Engagements, link clicks (FB), audit starts

## Method

Same topic; arm A native; arm B link with `company_*` UTM to `/website-audit` or blog.

## Note

Industry “links are demoted” claims remain **hypothesis** unless Meta states otherwise — measure for JS Solutions.
