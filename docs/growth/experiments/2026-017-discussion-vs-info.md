# GROWTH-EXP-2026-017 — Comment-driven discussion vs informational post

**Status:** READY  
**Job:** ENGAGEMENT vs AUTHORITY

## Hypothesis

Genuine discussion prompts (real local-business questions) increase comments and meaningful interaction predictions vs pure informational broadcast — without triggering engagement-bait demotion.

## Primary metric

Comments + reply depth

## Secondary

Reach, shares, follows

## Prompt style

Ask for experience/advice (“What’s the #1 website issue you see for local businesses?”) — not “Comment YES if…”
