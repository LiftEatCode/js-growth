# Weekly Search Review

Search growth is slower than Facebook. **Do not manufacture daily SEO busywork.**

## Cadence

Weekly (or biweekly while Stage 0).

## Questions

1. Did impressions increase vs prior week / baseline?
2. Did clicks increase?
3. Did new queries appear? (or still INSUFFICIENT_DATA?)
4. Did new pages receive impressions?
5. What pages gained/lost (when data exists)?
6. Is CTR actionable yet? (≥ ~100 impressions per query/page)
7. Which opportunities moved status?
8. What content should be created next (NOW band)?
9. What should be refreshed?
10. Any indexation / sitemap / canonical issues?

## Rules

- Baseline V1 remains immutable.
- Export zeros ≠ known zeros without context.
- Facebook metrics stay separate.
- No ranking guarantees in notes or client updates.
