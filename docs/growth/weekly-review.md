# Weekly Growth Review

Do not manufacture daily busywork. Review weekly (or when a window matures).

Operator UI: `/reports/growth` · `/reports/growth/intelligence` (Cross-Channel) · conversion · attribution · follow-up · local · content

**CROSS_CHANNEL_INTELLIGENCE_VERSION = 1** provides deterministic answers for the questions below from persisted evidence (no AI narrative).

## Questions

1. What changed? (Comparable windows only — otherwise **UNKNOWN**, not invent %)
2. What needs action? (NOW from Cross-Channel + Follow-up)
3. What are we waiting on? (WATCH · active experiments · GBP API allowlisting)
4. What evidence is still weak? (INSUFFICIENT_DATA / WEAK / early search)
5. Where is the current bottleneck? (Cross-Channel bottlenecks — only if evidence exists)
6. What should we **NOT** work on this week? (Conflicting experiments; CTR below impression floors; daily GBP API retries while allowlisting pending)
7. What experiments are active? (Facebook sequence · GBP-001… · content/search review windows)
8. What commercial items need attention? (Overdue leads · opportunities · proposals · agreements · payments)
9. What content / search / local reviews are due?
10. Did attribution coverage improve? (Compare knownRate when windows comparable; never rewrite historical UNKNOWN)
11. What generated **inbound** leads vs **outbound** prospects?
12. What generated opportunities?
13. Where is attribution UNKNOWN vs DIRECT vs known channel?
14. Where is funnel drop-off — and is the sample usable?
15. Are Facebook/GBP posts that need website traffic using canonical tagged URLs?
16. What is first-response median (28d)? Is sample `INSUFFICIENT_DATA` or usable?
17. Any contact submissions still awaiting explicit Create Lead?
18. Did we run **Sync Profile** + **Sync Performance** on `/reports/growth/local` this week (when connected)? Fall back to manual Insights if disconnected. Blank = NOT_CAPTURED; `0` = observed zero.
19. Any GBP checklist exceptions vs business facts?
20. Is GBP-001 still the active experiment — reviewing sync exceptions only?

## Rules

- Never mix outbound prospecting counts with inbound website leads.
- Unknown attribution is useful — do not hide it. Do not force UNKNOWN into DIRECT.
- Commercial proximity outranks marketing busywork (payment / overdue lead > GBP description polish).
- ROI_NOT_AVAILABLE until cost + strong revenue attribution exist.
- Growth Baseline V1 remains immutable.
- No auto-email, auto-status, auto-opportunity, auto-publish.
- Do not rewrite historical UNKNOWN audits.
- Do not invent GBP metrics or Map pack rankings. GSC ≠ GBP Insights.
- `GBP_API_APPROVAL_PENDING` is a dependency/WATCH — not a daily ERROR.
- No fake Growth Score.
