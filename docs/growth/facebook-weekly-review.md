# Facebook Weekly Review

**Cadence:** Weekly (operator)  
**Inputs:** Meta Business Suite / Professional Dashboard Insights, `/reports/growth` Facebook panel, content ledger, UTM/first-party attribution  
**Baseline anchor:** Growth Baseline V1 (do not overwrite)

---

## Checklist questions

1. **What increased reach / views?** Which posts, jobs, formats, publishers?  
2. **What reached non-followers?** Did non-follower % change vs prior week / baseline?  
3. **What caused engagement?** Reactions vs comments vs shares — any meaningful threads?  
4. **What drove Page visits?**  
5. **What gained followers?** Absolute followers, net change, % growth. Visit → follow only if data supports it.  
6. **What drove qualified website traffic?** Facebook sessions / landings (GA4 + first-party).  
7. **What drove audits?** Starts / submissions / completions with Facebook attribution.  
8. **What created opportunities?** Only when attribution is supportable — else mark NOT ATTRIBUTABLE.  
9. **Which posts produced nothing?** Stop or redesign.  
10. **Which content deserves iteration?**  
11. **What should we stop doing?**  
12. **What should we test next?** Link experiment ID.
