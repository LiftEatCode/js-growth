# JS Solutions Planning

This directory contains the strategic planning documents for JS Solutions.

Unlike the documentation found in `/docs`, these files track the current state of the business, upcoming work, milestones, and long-term vision.

These documents should be reviewed at the beginning and end of every work session.

---

## Purpose

The Planning directory serves as the command center for JS Solutions.

It answers four questions:

- Where are we today?
- Where are we going?
- What are we working on next?
- What ideas should we not forget?

## Workflow

Every work session should follow this process:

1. Review Current Sprint
2. Select the highest priority task
3. Complete the work
4. Update documentation
5. Update the roadmap
6. Commit changes
7. Push to GitHub

This ensures the repository always reflects the current state of the business.
